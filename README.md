# MCQ Practice Platform

A simple web-based MCQ Practice Platform developed as a mini project to help students practice multiple-choice questions and receive instant feedback.

# Features

* Clean and responsive user interface
* Daily MCQ practice
* Subject-wise question organization
* Questions dynamically fetched through REST APIs
* Admin can add new questions
* Newly added questions are displayed on the platform
* Question count is updated dynamically
* Instant answer feedback
* Simple and user-friendly navigation

# Tech Stack
->Frontend
* HTML
* CSS
* JavaScript
->Backend
* Node.js
* Express.js
* REST API
->Database
* MySQL

#Note

This project currently focuses on the core MCQ practice functionality. It does not include authentication, admin login, student profiles, or a separate user management system.
